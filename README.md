## Overview

Orpheon is a standalone desktop player focused on a modern library UI while keeping libVLC as the decode/playback engine. The frontend is Vue 3 + Pinia; the backend is a Tauri 2 app with Rust crates for libVLC FFI, media scanning, and settings.

| Layer | Stack |
|-------|--------|
| UI | Vue 3, Vite, Pinia, Vue Router, vue-i18n (EN / RU) |
| Shell | Tauri 2 (Windows first; WebView2) |
| Engine | libVLC 3.x (`src-tauri/crates/libvlc`, `libvlc-sys`) |
| Data | SQLite — library scan / playlists, settings / resume / streams |

## Features

- **Local library** — scan folders for video and audio, browse, continue watching, recent history
- **Playback** — play / pause, seek, volume, softvol ceiling, resume positions
- **Video surface** — native HWND embed on Windows (software RGBA path elsewhere)
- **Tracks & EQ** — audio / subtitle / chapter selection, 10-band equalizer
- **Network streams** — save and play HTTP(S) / RTSP-style MRLs with optional artwork URLs
- **Playlists** — create, rename, add items from the library
- **Preferences** — large VLC-aligned prefs bag, theme, language, privacy (clear history)
- **Artwork** — sidecar covers and generated thumbs cached under the app data dir (asset protocol)

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) 22+
- [Rust](https://rustup.rs/) stable (see `rust-toolchain.toml`)
- [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) (Windows)
- libVLC 3.x — either a system VideoLAN install **or** a populated `vendor/vlc` tree

> [!IMPORTANT]
> On Windows, DLLs must sit next to the executable at process start. Prefer `.\scripts\vendor-libvlc.ps1` so `npm run tauri:dev` / build can copy vendored libVLC automatically.

### Install and run

```powershell
git clone https://github.com/gmlrep/orpheon.git
cd orpheon
npm install

# if vendor/vlc is empty:
.\scripts\vendor-libvlc.ps1

npm run tauri:dev
```

UI-only shell (no libVLC link):

```powershell
cd src-tauri
cargo run --no-default-features
```

### Project layout

```

src-tauri/
  src/                    Tauri commands, poller, HWND embed, artwork
```

## Packaging

> [!TIP]
> Full Windows packaging notes live in [`packaging/README.md`](packaging/README.md).

```powershell
# Ensure vendor/vlc exists first
.\scripts\vendor-libvlc.ps1   # or scripts\ci-prepare-vlc.ps1 in CI

npm run tauri:build
```

libVLC is embedded via `bundle.resources` in `src-tauri/tauri.conf.json` (`libvlc.dll`, `libvlccore.dll`, `plugins/` next to `Orpheon.exe`).

Optional portable folder (no installer):

```powershell
$exe = Get-ChildItem -Recurse src-tauri\target\release\Orpheon.exe |
  Select-Object -First 1 -ExpandProperty FullName
.\scripts\bundle-libvlc.ps1 -OutDir dist\win -ExeSource $exe
```

**CI** (`.github/workflows/ci.yml`): typecheck, Vitest, `cargo test`, Windows Tauri build, portable artifact.  
**Release** (`.github/workflows/release.yml`): tag `v*` → GitHub Release with Windows artifacts.

## Troubleshooting

**Blank / white window**  
Confirm `devUrl` matches Vite (`http://localhost:1420`) and that `npm run tauri:dev` started the frontend. Open WebView DevTools (`Ctrl+Shift+I`) for console errors.

**`STATUS_DLL_NOT_FOUND` / engine never ready**  
Populate `vendor/vlc` and rebuild so DLLs are copied beside the exe. Check logs for `libVLC init failed` / `engine://ready`.

**Missing library thumbs**  
Artwork is served only from the app artwork cache (`…/com.orpheon.app/artwork/**`). Sidecar covers are copied into that cache on resolve; clear negative-cache sentinel or rescan if needed.

**Permission denied on `invoke`**  
App commands are ACL-gated. After adding a `#[tauri::command]`, register it in `src-tauri/build.rs` (`APP_COMMANDS`) and add `allow-<kebab-name>` to `src-tauri/capabilities/default.json`.
